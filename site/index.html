03 / BEFORE YOU BEGIN

Three rules.
No shortcuts.

A working setup starts with good information and reversible decisions.

01

There is no universal EFI.

Use exact hardware IDs and the correct OpenCore release. Never copy a random EFI folder and assume it fits.

↗
02

Protect your existing system.

Back up important files and boot entries. Understand every disk operation before you run it.

↗
03

Change one thing at a time.

Keep a known-good backup, record each change, and validate the configuration before booting.

↗
