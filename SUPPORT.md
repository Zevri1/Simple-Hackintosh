# Support and Troubleshooting

This repository is an educational guide, not a promise of support for every PC or macOS release.

Before asking for help:

1. Read the matching chapter in `docs/`.
2. Check the official Dortania guide for your platform.
3. Run the `ocvalidate` version that matches your OpenCore package.
4. Record the exact point where startup fails.
5. Use `templates/problem-report.md` to prepare a redacted report.

Never publish serial numbers, MLB values, SystemUUID, ROM values, Apple account information, passwords, MAC addresses, or unredacted logs.

The best place to confirm a technical setting is the current official project documentation for the tool or driver involved.
