# Publish This Starter Pack to GitHub

## Upload the repository files

1. Extract `simple-hackintosh-starter-pack.zip`.
2. Open the extracted `Simple-Hackintosh` folder.
3. Open your GitHub repository in a browser.
4. Choose **Add file → Upload files**.
5. Drag the contents of the extracted `Simple-Hackintosh` folder into the upload area. Upload the folders as well as the root files so that `docs/`, `images/`, and `templates/` keep their directory structure.
6. Review the file list. The new `README.md` and `LICENSE` are intended to replace the existing versions; confirm that this is what you want.
7. Enter a commit message such as `Add detailed Hackintosh documentation` and choose **Commit changes**.

Do not upload a private EFI folder, personal SMBIOS values, macOS installer images, Apple firmware, or third-party binaries without permission.

## Set the repository Social Preview image

The file `social-preview.jpg` at the project root is prepared for GitHub's Social Preview field. It is 1280 × 640 pixels and under 1 MB.

1. Open the repository's main page.
2. Select **Settings**.
3. Find **Social preview** in the repository settings.
4. Select **Edit**.
5. Choose **Upload an image...** and select `social-preview.jpg`.
6. Save/confirm the change if GitHub asks.

GitHub recommends at least 640 × 320 pixels and 1280 × 640 pixels for best display; PNG, JPG, or GIF files must be under 1 MB.

The `images/installation-flow.jpg` copy is used inside the README. The Social Preview controls the image shown when the repository link is shared on supported social platforms; it does not change the GitHub account avatar.
